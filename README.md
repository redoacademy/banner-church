# 旌旗教會・屬靈資源與讀經中樞 (Banner Church Hub)

歡迎來到**台中旌旗教會（Banner Church）**專屬屬靈資源與讀經中樞！
本儲存庫旨在將教會相關的靈修、讀經進度、小組聚會與服事材料進行獨立且有系統的組織架構管理。

🌐 **公開線上閱讀網站（GitHub Pages）**：  
👉 [https://redoacademy.github.io/banner-church/](https://redoacademy.github.io/banner-church/)

## 🏛️ 資料整理組織架構 (Architecture)

本空間將教會領域之內容完整獨立於商業專案之外，劃分為三大核心專區：

```text
banner-church/
├── index.html                     # 🌐 教會資源導航中樞（GitHub Pages 首頁）
├── current/                       # 🔗 永遠指向「當週最新」的快捷網頁
│   ├── index.html                 # 當週小組分享指引與講稿
│   └── scripture.html             # 當週完整經文彙整（和合本全文＋箴言默想）
├── bible-tour/                    # 📖【專區一】聖經旅行團（三年讀經計畫進度與存檔）
│   ├── README.md
│   └── 2026/
│       └── 1019_1025_1kings_3-9/  # 2026/10/19～10/25 列王紀上 3～9 章
├── small-group/                   # 👥【專區二】旌旗小組生活與聚會服事材料
│   └── README.md                  # 小組破冰、代禱事項、分享稿範本
└── sunday-messages/               # ⛪【專區三】主日信息與講道筆記
    └── README.md                  # 主日講道重點與靈修日記
```
